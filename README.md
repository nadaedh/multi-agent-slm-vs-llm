# Benchmarking LLMs vs Multi-Agent Architectures of SLMs:

Project Goal

The objective of this project is to compare the intelligence and performance of a single Large Language Model (LLM) against multi-agent systems composed of Small Language Models (SLMs).
The key research question is:

Can multiple smaller cooperating agents (SLMs) reach or even surpass the performance of a single large LLM on complex reasoning tasks?
